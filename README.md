## 🚀 Featured Projects

### 🧪 LabSync — DSA Lab Code Management System

A full-stack application designed to help students store and manage their DSA lab programs from different lab computers.

**Tech:** React • TypeScript • Node.js • Express.js • MongoDB

**Features:**
- 🔐 User registration and login
- 📚 Store and manage programming lab programs
- 🔎 Search and filter programs
- ✏️ Edit and delete programs
- 👤 User-specific program management
- 🔑 JWT authentication

🔗 **Repository:** [LabSync](https://github.com/manthansingh104-cmd)

---

### 🏆 CampusPlay — Campus Sports Management Platform

**One Campus. Every Game. Every Player.**

A platform designed to simplify inter-class and inter-block sports competitions.

**Tech:** React • TypeScript • Tailwind CSS • Node.js • Express.js • Database

**Features:**
- 🏟️ Discover campus sports events
- 👥 Team and individual registration
- 📅 Fixtures and schedules
- 🏆 Results and leaderboards
- 📊 Organizer event management
- 🤖 AI assistant integration

🔗 **Repository:** [CampusPlay](https://github.com/manthansingh104-cmd/CampusPlay)
